# Evidence bundle downloads

Each link downloads one GitHub artifact ZIP. Every ZIP contains all current
official evidence JPEGs (with flattened names such as `L22_V029_054.jpg`), a
`README.md` frame list, and the rank-1 source video for manual review. The
artifacts expire after 7 days. GitHub requires the downloader to sign in,
even for this public repository.
